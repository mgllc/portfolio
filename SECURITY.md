# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |
| older   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please **do not**
open a public issue.

Instead, report it privately via [GitHub's private vulnerability reporting](../../security/advisories/new)
for this repository, or email **{{CONTACT_EMAIL}}**.

Please include:

- A description of the vulnerability and its potential impact
- Steps to reproduce (proof-of-concept code if possible)
- Any suggested remediation

You can expect an initial response within **5 business days**. This is a
personal/portfolio project maintained on a best-effort basis, not a
commercially supported product — please scope expectations accordingly.

## Scope

This policy covers the code in this repository. It does not cover
third-party dependencies (report those upstream) or infrastructure not
managed in this repo.
